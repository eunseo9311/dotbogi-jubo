# 돋보기 주보

사랑의교회 주보를 70대 이상 어르신이 읽기 쉽게 큰 글씨로 옮긴 페이지입니다.

- 주소: https://eunseo9311.github.io/dotbogi-jubo/ (첫 화면은 가장 최근 주보)
- 지난 주보: `https://eunseo9311.github.io/dotbogi-jubo/2026-09-27/`처럼 날짜 주소로 남습니다. 페이지 맨 아래 '다른 주 주보 보기'에서도 고를 수 있습니다.
- 화면: 위쪽 1·2 버튼으로 예배 순서와 이번 주 소식·기도를 오갑니다. 주소 끝에 `#news`를 붙이면 소식 화면이 바로 열립니다.
- 글씨: 기본은 본문 24pt, 제목 36pt 이상입니다. 맨 위 버튼으로 50%부터 200%까지 10%씩 바꿀 수 있고, 고른 크기는 각자의 브라우저에 저장됩니다.
- 색: 흰 바탕에 검정 글씨, 사랑의교회 로고 빨강(#e4004c)과 같은 계열의 짙은 빨강(#b0003a)을 씁니다.
- 원래 주보에 있던 성도 이름, 휴대폰 번호, 계좌번호, 결혼·장례·새가족 명단은 넣지 않습니다.
- 검색 결과에는 나오지 않게 해 두었습니다(`noindex`). 링크를 받은 분이 열어 보는 용도입니다.

## 매주 자동으로 만들기

이 Mac의 Claude 앱 예약 작업이 매일 밤 9시에 [사랑의교회 주보 게시판](https://www.sarang.org/info/sun_bulletin.asp)을 확인합니다. 새 주보가 올라와 있으면 사진 6장을 받아 내용을 옮기고, 사진과 대조 검사를 통과했을 때만 이 저장소에 올립니다. 앱이 꺼져 있던 날은 다음에 앱을 켤 때 확인합니다. 작업 순서와 규칙은 [tools/AUTOMATION.md](tools/AUTOMATION.md)에 있습니다.

| 파일 | 하는 일 |
|---|---|
| `data/YYYY-MM-DD.json` | 한 주 주보의 내용. 매주 이 파일만 새로 씁니다 |
| `tools/fetch_bulletin.py` | 게시판에서 최신(또는 `--date`로 고른) 주보 사진을 찾고 `--download`로 `work/`에 받습니다 |
| `tools/template.html` | 페이지 틀(디자인, 글씨 크기 버튼, 화면 전환) |
| `tools/build.py` | 내용을 틀에 넣어 `index.html`과 `YYYY-MM-DD/index.html`을 만듭니다. 010 번호나 계좌번호 모양의 숫자가 있으면 멈춥니다 |
| `og-image.jpg` | 카카오톡 등에서 링크를 보낼 때 뜨는 미리보기 그림 |

손으로 고칠 때는 `data/`의 JSON을 고친 뒤 `python3 tools/build.py`를 돌리고, 바뀐 파일을 main에 올리면 됩니다. 주소가 바뀌면 `tools/build.py`의 `SITE_URL`도 새 주소로 고쳐 주세요.

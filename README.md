# 돋보기 주보

사랑의교회 주보를 70대 이상 어르신이 읽기 쉽게 큰 글씨로 옮긴 페이지입니다. 파일 하나(`index.html`)로 동작합니다.

- 주소: https://eunseo9311.github.io/dotbogi-jubo/
- 화면: 위쪽 1·2·3 버튼으로 예배 순서, 이번 주 소식과 기도, 성경 그림 만들기(주보 담당자용)를 오갑니다. 주소 끝에 `#news`나 `#picture`를 붙이면 그 화면이 바로 열립니다.
- 글씨: 본문 24pt, 제목 36pt 이상입니다. '크게 +' 버튼으로 두 단계 더 키울 수 있고, 고른 크기는 각자의 브라우저에 저장됩니다.
- 색: 흰 바탕에 검정 글씨, 사랑의교회 로고 빨강(#e4004c)과 같은 계열의 짙은 빨강(#b0003a)을 씁니다.
- 원래 주보에 있던 성도 이름, 휴대폰 번호, 계좌번호, 결혼·장례·새가족 명단은 넣지 않았습니다.
- 검색 결과에는 나오지 않게 해 두었습니다(`noindex`). 링크를 받은 분이 열어 보는 용도입니다.

주보가 바뀌면 `index.html` 내용을 고쳐 main에 올리면 다시 배포됩니다. 주소가 바뀌면 `index.html` 머리 부분의 `og:url`, `og:image` 값도 새 주소로 고쳐 주세요.
